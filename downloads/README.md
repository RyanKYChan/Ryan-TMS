[Download RYAN TMS v0.2.0](https://github.com/RyanKYChan/Ryan-TMS/raw/refs/heads/main/downloads/ryan-tms-windows-v0.2.0.zip)

Install Node.js 24 from https://nodejs.org/en/download, extract the archive, and run `START-TMS.cmd` inside the `Ryan-TMS` folder. Keep the command window open while using the dashboard.

**Updating:** Close the old app first. Back up its `data` folder. Extract into the same parent folder so the new `Ryan-TMS` folder merges with the existing folder, replacing application files. Do not delete the old folder or its `data` directory. The ZIP contains no databases. Restart the launcher and check v0.2.0 in the footer.

This update recognises generic VIN No / Model / Loading / Unloading packing lists, extracts city/postcode from recognised address endings, remembers custom mappings, supports shared POL/POD details, and adds bulk editing to the unit register.
