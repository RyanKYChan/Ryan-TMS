# Windows download

Download `ryan-tms-windows.zip` using GitHub's raw-file download action, then extract the entire archive. Install Node.js 24 from https://nodejs.org/en/download and double-click `START-TMS.cmd` inside the extracted `Ryan-TMS` folder. Keep the command window open while using the app.

The ZIP includes the dashboard, packing list importer, vehicle register, and load planner. It contains no real vehicle records or workspace databases. It needs internet access on first start to install locked npm dependencies.
