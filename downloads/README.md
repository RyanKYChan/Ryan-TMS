# Windows download — v0.7.1

[Download RYAN TMS v0.7.1](https://github.com/RyanKYChan/Ryan-TMS/raw/refs/heads/main/downloads/ryan-tms-windows-v0.7.1.zip)

Install Node.js 24 from https://nodejs.org/en/download, extract the archive, and run `START-TMS.cmd` inside the `Ryan-TMS` folder. Keep the command window open while using the dashboard.

**Updating:** Close the old app first. Back up its `data` folder. Extract into the same parent folder so the new `Ryan-TMS` folder merges with the existing folder, replacing application files. Do not delete the old folder or its `data` directory. The ZIP contains no databases. Restart the launcher and check v0.7.1 in the footer.

This patch shows date-only milestone values by default in carrier detail and load announcement exports. Enable Include hours and minutes when a saved time is needed; ISO timestamps are available when times are included. Preview, clipboard tables and CSV follow the same option. Stored dates and times remain intact. Existing data is retained when updating as described above.
