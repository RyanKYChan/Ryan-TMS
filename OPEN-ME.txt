RYAN TMS v0.11.0 - Open the dashboard on your Windows computer

1. Install Node.js version 24 from https://nodejs.org if you do not have it.
2. Extract the entire ZIP file to a folder on your computer.
3. Open the extracted Ryan-TMS folder and double-click START-TMS.cmd.
4. The first start installs dependencies, so internet access is needed.
5. The launcher opens the working dashboard in Edge after the app is ready.
6. Keep the command window open while using the app.

The dashboard includes:
- Project type: VIN transport or ad hoc container stripping without VINs.
- Carrier & truck bank: reusable carriers, trucks, trailers and drivers.
- Saved loading/unloading yards and bulk paste of carrier truck messages.
- Yard-arrival deadlines, calendar entries and batch announcements.
- Truck visits: spot-market bookings, plate/driver swaps and milestones.
- Yard calendar and copy-ready announcements, with re-announcement alerts.
- Confirmed VINs: add and link VINs after stripping, even after pickup.
- Export carrier details: copy models, VINs, route details and chosen columns.
- Export announcement: copy saved VINs, models, truck plates and ETD per load.
- Export load announcements: multiple built loads separated with blank rows.
- Project settings: rename the project and edit its customer/brand.
- Volume settings: edit the estimate or follow packing-list VIN totals.
- Delete project: type its name to confirm deleting its records.
- Calendar: planned pickups, deliveries, month navigation and carrier filter.
- Pricing & analysis: project cost/revenue per load or unit, with bulk rates.
- Ready to go: Reference / Appointment # added; actual stages take precedence.
- Schedule changes: saved date-change warnings with load and VIN details.
- All project loads: dashboard totals across every carrier.
- Import units: paste VINs or rows copied from Google Sheets.
- Packing lists: organise your imported vehicle manifests.
- Load builds: choose a carrier and paste its complete sheet batch.
- Unit register: track ETD, ETA, ATD, ATA, T1 and your other sheet fields.
- Explore a sample project: try clearly labelled demonstration data first.
- Bulk edit: select vehicles in Unit register and edit shared fields together.
- Generic imports: VIN No, Model, Loading and Unloading are recognised.
- Rows per page: show 50, 100, 200, 400, or all VINs.
- Select next: choose a batch of VINs in original packing-list order.
- Assign / change carrier: allocate 200 VINs or any selected batch at once.
- Carriers: a separate workspace for each carrier and a progress comparison.
- Paste sheet update: preview changed milestones and gap-based load builds.

PACKING-LIST PRIORITIES AND DASHBOARDS (v0.11.0)
Open Packing lists, then Open dashboard for the batch you need to focus on.
The list dashboard has its own movement pipeline, planning gaps, carrier progress,
load membership, upcoming movements, actual milestones and recent activity.
Click any count to work with the corresponding VINs in the register.
Export this list exports that list only. Shared loads show your list's share;
opening a whole shared load can affect VINs from other lists too.

Edit priority & planning to set priority, onward objective, hold reason, next
step and a review date. Example: On hold - awaiting client contract for onward
transport or storage. Record the next client decision and a review date so a
stationary batch has an explicit explanation. The project overview surfaces
priority lists and holds. A hold does not change saved VIN stages or movements.

If you already use v0.10, close it and launch this update. The same permanent
database is used; a full safety backup is created before the schema upgrade.
Use v0.11 or later afterward: v0.10 refuses the newer schema.
If upgrading from an older app-folder database, follow the import steps below.

UPDATING / FIRST-TIME DATABASE IMPORT
1. Close all previous Ryan-TMS command windows.
2. Extract the new ZIP anywhere and run START-TMS.cmd.
3. On first launch, choose Import Existing Database and select the most recent
   previous Ryan-TMS folder. You can also paste its path.
4. Confirm the previous application is closed, then Inspect existing database.
5. Check the source path and record counts, then Confirm import.
   Keep the old data folder intact, including WAL and SHM files. Do not copy only
   tms.sqlite. SQLite safely includes committed WAL changes during import.
   Original database files are never deleted.
6. Data is now stored at %LOCALAPPDATA%\Ryan-TMS\data\tms.sqlite.
   Every later update opens it automatically, wherever the new ZIP is extracted.
   Never run two versions at once. Do not point older releases at this database.
7. For a new installation without existing data, expand Start without an existing
   database and type NEW. Do not do this if you have records to import.

BACKUP / RESTORE
Open Data & backups in the sidebar to see the active database location.
Create & download database backup lets you choose where to save a complete copy.
Backups include every project, VIN, carrier, load, movement, setting and history.
To restore: select a Ryan-TMS backup, review its counts, type RESTORE and confirm.
Current data is backed up before restoration. A bad backup is rejected.
Automatic backups are also created before numbered schema upgrades.
If the database cannot be accessed, startup fails instead of resetting your data.
A missing expected database must be restored; do not create an empty replacement.

BULK CARRIER REASSIGNMENT
In Unit register, filter the old carrier and select the VINs to move.
Untick Without a carrier only to use Select next for already assigned VINs.
Select all matching vehicles includes VINs across all pages.
Choose Assign / change carrier, select the new carrier, Review assignments,
then Confirm assignment. Review shows all old/new carriers and load removals.
Previous planned load links and trucks are cleared for transferred VINs.
Routes, dates, notes, packing lists, order and history are retained.
Departed/delivered vehicles and VINs linked to truck visits are protected.

For carrier sheets, open the destination carrier (even if it has no VINs yet),
paste the new batch, and Review changes. Tick Confirm assignment changes for
all VINs and apply once. Carrier moves and sheet updates save together.
Blank dates keep saved dates. New sheet truck details replace old ones;
otherwise the previous carrier's truck is cleared. Omitted VINs stay unchanged.
If a pasted Carrier column is present, it must match the destination carrier.

TO START AN AD HOC CONTAINER STRIPPING PROJECT
Click New project and choose Ad hoc container stripping - truck visits.
Enter the default pickup yard. Volume can be 0 when unknown.
Use Carrier & truck bank to save contacts and reusable trucks/drivers.
Click New truck visit, or + on a calendar day, to plan a pickup without VINs.
The new visit can prepare its yard announcement automatically after saving.
Copy the table to your usual yard message; Mark as announced after sending.
Copying alone does not mark it announced, and the app does not send messages.

TO BOOK SEVERAL TRUCKS FROM A CARRIER MESSAGE
Open Project settings and save Default pickup yard and Default unloading yard.
Click Bulk add trucks, choose the carrier, and paste the carrier message.
Click Read pasted trucks, check truck/trailer/driver rows, then Book 4 trucks.
You can correct/remove rows and apply shared dates, yards and comments.
Today till 18:00 ... arrive sets a shared yard-arrival deadline, not ETD/ETA.
Calendar > Arrivals at loading yard shows these appointments.
Announcements stay date-only unless you tick Include hours and minutes.
The whole batch is validated together; retries do not create duplicate visits.

TO HANDLE DRIVER SWAPS AND DROPOUTS
Open Truck visits, then Edit / swap truck on the booking.
Change the plate, driver, carrier or slot and save. The visit is retained.
Changed announced visits are flagged Needs re-announcement.
Use Yard announcements to prepare and confirm the updated message.
Use Cancelled for a dropout; a visit without actual departure/arrival can be
re-planned. Existing visit history and other bookings are kept.

TO TRACK PICKUP MILESTONES AND ADD VINS LATER
ETD/ATD mean departure from the pickup yard.
ETA/ATA mean arrival at the delivery destination.
At yard is a separate ops stage for arrival at the pickup yard.
Enter actual departure/arrival when known. Actual milestones complete the
pickup stage. For historical pickups, enter their actual ATD explicitly.
To add VINs later, open the visit and click Add VINs after stripping.
Paste VINs or VIN/model rows. Repeat pastes update matching VINs in place.
Confirmed VINs shows all those records, linked to their truck visits.
Visit edits sync linked VIN plans and fill missing actual timestamps.
Reported actual quantity stays separate from the number of confirmed VINs.

TO COPY DETAILS TO CARRIER SHEETS
Open Carriers, choose a carrier, then Export carrier details.
Choose the rows and columns, then Copy table and paste into Google Sheets.
You can also Download CSV, or export selected VINs from Unit register.
Prices/revenue are optional; the default carrier export excludes them.
If clipboard access is blocked, use Manual copy / spreadsheet text,
Select export text, then Ctrl+C and paste into the first spreadsheet cell.

TO ANNOUNCE A LOAD
Open Load builds and click Export announcement under a detected load.
Or open a load, save any changed planning, then Export announcement.
The default table includes Load, VIN, Model, Carrier, Truck plate and ETD,
plus POL/POD city and Reference. Check any missing truck/ETD warnings.
Dates show the date only by default. Tick Include hours and minutes to add
the saved time. This works for announcements and carrier detail exports.
ISO dates with timezone is available when times are included.
Hiding the time does not change the dates or times stored in the TMS.
Copy table and paste into your announcement; sending is up to you.
Export load announcements above the cards exports all that carrier's loads.
Group loads with blank rows separates them; unbuilt VINs are excluded.

TO EDIT PROJECT NAME OR VOLUME
Open Project settings next to Import units on the dashboard.
Edit Project name, Customer / brand or Estimated units, then save.
Choose "Use the packing-list total automatically" to base progress on the
actual unique VIN count. The original estimate is kept for switching back.
Repeated VINs are not counted twice; new VIN imports update the total.
The imported count is the real number of VIN records, separate from estimates.

TO DELETE A PROJECT
Open Project settings, then Delete project.
The confirmation shows what will be removed. Back up your data folder first
if you may need to recover the project. CSV export contains units only.
Type the current project name, then Permanently delete project.
Other projects stay saved. You can create a new project if none remain.

TO USE PROJECT LOAD PRICING
Open Pricing & analysis. Choose Cost basis = Per load.
Enter Load cost default (EUR). Choose Fill blank prices or Replace prices.
Choose Revenue basis = Per unit or Per load and enter the matching default.
Click Save project rates. Blank default amounts do not change existing prices.
Only the selected bases count toward totals; missing prices are flagged.
To price selected loads differently, use the table and bulk pricing controls.

TO FOLLOW UP CHANGED DATES
Review the highlighted schedule warnings before applying a carrier paste.
After applying, open Schedule changes to see old/new ETD/ETA and affected VINs.
Mark followed up after checking with the carrier. History remains available.

TO ASSIGN YOUR FIRST 200 VINS
Open Unit register. Enter 200 under Select next, then Select 200 VINs.
Click Assign / change carrier, enter the name, Review assignments, then confirm.
Repeat for the next carrier: allocated VINs are skipped by default.
Open Load builds, click the carrier, then Paste full batch for that carrier.
Paste the entire sheet, including headers, load gaps and unassigned VINs.
Separated load groups are recognised; the unassigned remainder stays unbuilt.
Review changes, then Apply update. Repeating a paste reuses existing loads.
Blank cells keep saved values. Departed/delivered load assignments are kept.
Turn off membership sync for a dates-only or partial paste.

To repair an earlier packing list import, re-paste it with the same name.
Matching VINs update in place; you do not need to recreate the vehicles.

If you explicitly create a new database, its Maxus project starts empty with a planning target of 400 units.
Your data saves to %LOCALAPPDATA%\Ryan-TMS\data\tms.sqlite, outside this folder.
The download includes no real vehicle records or cloud workspace database.

ChatGPT's cloud environment settings page does not display this web app.
Opening client/index.html or dist/index.html directly is also not sufficient:
the app needs its local web server and database API, started by the launcher.

If Edge does not open automatically, enter localhost:3000 in Edge's address
bar AFTER the command window says "Dashboard is ready".

Do not delete this folder after importing real data. Use Export CSV or
run "npm run backup" from this folder to make a backup.

This version runs locally on your computer. Shared online hosting and
automatic Google Sheets sync are not included.
